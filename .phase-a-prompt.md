## 5. Auth pattern (à conserver à l'identique)

- **Token discovery** : URL hash `#token=...` au premier chargement → parsé par `lib/token.ts` → stocké en `sessionStorage` (clé `loomflo.token`) → effacé du URL pour ne pas fuiter dans DevTools/historique.
- **HTTP** : header `Authorization: Bearer <token>` sur toutes les requêtes authentifiées.
- **WebSocket** : `Sec-WebSocket-Protocol: loomflo.bearer, <token>` (token jamais en query string).
- **Daemon discovery** : `~/.loomflo/daemon.json` contient `{ port, token, pid, version }`. Le CLI `loomflo dashboard` ouvre `http://127.0.0.1:<port>/#token=<token>`.

→ La migration ne change PAS ce pattern. `lib/token.ts` et `lib/ws.ts` existants peuvent être réutilisés tels quels.

#### Procédure de conversion par fichier

Pour chaque .jsx :

1. **Renommer** `.jsx` → `.tsx`, déplacer au bon path
2. **Remplacer le préambule** :
   ```tsx
   // Avant (proto)
   const { useState, useEffect, useRef, useMemo, useCallback, useLayoutEffect } = React;

   // Après
   import {
     useState,
     useEffect,
     useRef,
     useMemo,
     useCallback,
     useLayoutEffect,
   } from "react";
   ```
3. **Importer le CSS dédié** au lieu du `<link>` HTML :
   ```tsx
   import "./WorkflowPage.css";  // copier depuis le proto, renommé
   ```
4. **Ajouter types pour les useState** :
   ```tsx
   // Avant
   const [open, setOpen] = useState(false);

   // Après (déduire le type depuis l'usage ; quand pas évident, expliciter)
   const [open, setOpen] = useState<boolean>(false);
   const [project, setProject] = useState<Project | null>(null);
   ```
5. **Ajouter types pour les props composants** :
   ```tsx
   // Avant
   function NodeCard({ node, onSelect }) { ... }

   // Après
   interface NodeCardProps {
     node: Node;
     onSelect?: (id: string) => void;
   }
   function NodeCard({ node, onSelect }: NodeCardProps) { ... }
   ```
6. **Remplacer les `window.xxx` globaux** par des imports propres :
   ```tsx
   // Avant
   const { detectIntent, buildResponse } = window.LoomChatBrain;

   // Après
   import { detectIntent, buildResponse } from "../lib/loomBrain.js";
   ```
7. **Supprimer les `Object.assign(window, { ... })`** en fin de fichier.
8. **Pour les SVG inlinés** (icônes type Lucide), les laisser tels quels OU les extraire dans `src/components/icons/Icons.tsx` si plus de 50 occurrences.

## Risques & mitigations

| Risque | Mitigation |
|---|---|
| Conversion JSX→TSX trop longue (~15k LOC) | Faire fichier par fichier, commiter chaque page séparément |
| Tokens CSS qui se perdent | Vérifier visuellement page-par-page contre les HTML du proto |
| `window.xxx` globaux qui cassent en ESM | Lister tous les `Object.assign(window, ...)` du proto avant de migrer, créer des modules d'export propres |
| `lib/types.ts` qui diverge de `@loomflo/core` | Référence : `packages/core/src/types.ts` + `api/websocket.ts` |
| Tailwind v4 `@theme` qui ne pick up pas tous les tokens | Vérifier qu'on utilise `@import "tailwindcss"` en haut du `index.css` et que le `@theme` block contient tous les `--color-*` |
| Build prod qui échoue à cause de paths Windows-style | Utiliser uniquement des forward slashes dans les imports |
